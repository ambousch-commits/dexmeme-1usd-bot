# dexmeme-1usd-bot

Paper-trading Solana meme-coin bot targeting $1 net profit per trade with a 100+ trades/day research goal.

## Railway

- Runtime: Python 3.13+
- Start command: `python -m dexmeme.main`
- Dashboard is served from `/`
- Health endpoint: `/health`
- API stats: `/api/stats`

Paper mode only. Real-money execution is disabled.
